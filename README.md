# 🍔 Dheri Eats

A responsive fast-food restaurant website built with **HTML5 and CSS3**. The project focuses on creating a clean, modern, and user-friendly restaurant interface that works across different screen sizes.

## 🌐 Live Demo

**[View Dheri Eats](https://dheri-eats.vercel.app/)**

## ✨ Features

* 🏠 Home section
* ℹ️ About section
* 🍕 Featured dishes and menu
* 🖼️ Gallery section
* 🛒 Order Now section
* 🔐 Sign In / Sign Out interface
* 📱 Responsive design for different screen sizes
* 🎨 Custom styling and restaurant-themed layout

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**

## 📱 Responsive Design

The website is designed to adapt to different screen sizes, including desktop and mobile layouts.

## 🚀 Deployment

The website is deployed using **Vercel**.

**Live Demo:** [dheri-eats.vercel.app](https://dheri-eats.vercel.app/)
